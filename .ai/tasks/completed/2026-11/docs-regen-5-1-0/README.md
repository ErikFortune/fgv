## Summary

The committed generated API docs, last regenerated by #652 on 2026-08-21, are current again. `rush
build-docs` regenerated the twelve projects that have the script; six changed (`ts-extras`,

fixed with comment-only edits in `ts-utils`, `ts-json-base` and `ts-extras`, so it now exits 0.

## Decisions made during execution

- **`build-docs` warnings fixed after the first pass.** The first run exited 1 on 12 TSDoc
  warnings; the orchestrator extended scope to fix them (`result.md` § 5).
- **The six `ts-web-extras` `@inheritDoc` warnings were fixed by writing the comment, not the
  reference.** The inherited `{@inheritDoc FileTree.…}` in `ts-json-base`'s `InMemoryTreeAccessors`
  points into another package, which `ts-web-extras`'s typedoc build cannot see under any
  spelling; API Extractor could not resolve it either. The interface's text now sits in the two
  base-class comments, as the class's other methods already do.
- **"Regenerates cleanly" read as 0 errors and deterministic output.** The root run has 208 (196 after the
  fixes) unresolved-link warnings, the same class the per-package configs tolerate; two runs were
  byte-identical.
