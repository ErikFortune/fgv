### `personality-intake` ✅ (shipped 2026-10-01 via #711)

**Status: ✅ shipped via [#711](https://github.com/ErikFortune/fgv/pull/711).** Capture-only intake, no
package touched. PR into `integration/agent-tasks-v1`. Artifacts at
`.ai/tasks/completed/2026-10/personality-intake/`. *Written anticipating merge, per the artifact protocol.*

**Mission.** Turn PersonAIlity's open requests to fgv into one triageable inbox file per request, without
triaging them, so the orchestrator's context never ingests raw issues.

**What shipped.** 17 inbox findings, one per open `fgv-ask` issue: eight `ts-extras-mcp` asks (M1–M8),
five `ts-json-base` `JsonSchema` asks (J1–J5), the ai-assist `execute` signal, the `ts-random` weighted
pick, the `ts-agent-memory` `derivedFrom` docstring, and the browser barrel's missing `fromBase64Strict`.
Each finding cites its source and quotes its constraints, and the intake agent's voice is confined to
marked Observations.

**What changed shape.** A post-capture sweep tested the premise that older asks were done but unpublished.
**It did not hold:** none of the 17 is implemented on any fgv branch or open PR, including the three that
predate the 2026-10-01 MCP cluster. The delivered asks are among the 28 closed issues. The brief said not to
finalize; the user then asked for it, so the inbox drains from `completed/`.

**Open.** The closed asks were not swept against fgv, and PersonAIlity's notes from before the tracker
were not swept for asks that were never filed.
