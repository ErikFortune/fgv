# Interface: IMessageHrefAction

An actionable element attached to a message rendered as an external link.
Renderers display this as an `<a>` that opens in a new tab with
`noopener noreferrer`.

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="property-href"></a> `href` | `readonly` | `string` | External URL to open when the action is clicked. |
| <a id="property-label"></a> `label` | `readonly` | `string` | Action label |
| <a id="property-onaction"></a> `onAction?` | `readonly` | `undefined` | - |
