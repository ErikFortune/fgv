# Variable: edgeTargetConverter

> `const` **edgeTargetConverter**: [`Converter`](https://github.com/ErikFortune/fgv/tree/main/libraries/ts-utils/docs)\<[`IEdgeTarget`](../interfaces/IEdgeTarget.md)\>

Converter for a scope-qualified [IEdgeTarget](../interfaces/IEdgeTarget.md). Both `scope` and `id`
are required — the whole point of the scoped target is that a bare id is
ambiguous across scopes.
