# Variable: LINK\_TRAVERSAL\_UNWIRED\_MESSAGE

> `const` **LINK\_TRAVERSAL\_UNWIRED\_MESSAGE**: `string` = `'link traversal requires a backlink index; none configured'`

The loud-degradation message a retriever returns when a link-traversal axis
(`linkedFrom` / `linkedTo` / `hops`) is requested but no backlink index is
wired.
