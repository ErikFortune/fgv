# Variable: schemaNumberConstraintKeywords

The numeric constraint keywords of a `number` / `integer` node, in the order they are checked,
emitted and folded.

## Type

`readonly ["minimum", "exclusiveMinimum", "maximum", "exclusiveMaximum", "multipleOf"]`
