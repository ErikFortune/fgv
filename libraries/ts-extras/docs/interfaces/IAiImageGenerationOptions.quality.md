## IAiImageGenerationOptions.quality property

Quality tier. Accepted values differ per model:
- gpt-image-1: 'low' | 'medium' | 'high' | 'auto'
Other models ignore this field.

**Signature:**

```typescript
readonly quality: GptImageQuality;
```
