# Variable: HMAC_SHA256_KEY_SIZE

Key size in bytes for an HMAC-SHA256 key: the SHA-256 output length (RFC 2104's `L`).
Generated HMAC keys have exactly this length, and imported raw keys may not be shorter.

## Type

`number`
