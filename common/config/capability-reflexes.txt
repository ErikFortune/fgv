# Capability reflexes that MUST stay in the always-loaded router.
#
# Each line is a symbol an agent needs to be able to reach WITHOUT opening anything, because the
# reflex attached to it prevents a real defect: "use KeyStore, never roll your own PBKDF2",
# "read embeddingRefOf, never test embeddingRef for presence", "don't hand-roll a timeout + size
# cap + redirect loop".
#
# These fire for a reader who did not know to look. Behind a load-on-demand boundary they would
# only reach someone who already knew — the person who did not need them. That is why losing one
# is a CI failure rather than a review comment: the loss would be invisible in a bulk move.
#
# Symbols, not sentences, deliberately. A router entry will be reworded when it is compressed to
# one line, and a gate that breaks on rewording is a gate someone deletes. The symbol is the
# stable anchor.
#
# Verified by common/scripts/verify-capability-docs.mjs. To remove a line, the capability itself
# must be gone, and the removal ships in the same commit.
